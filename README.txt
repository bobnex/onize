FOR MY ONIZE — FINAL BIRTHDAY WEBSITE

Included:
- index.html (complete HTML with built-in CSS and JavaScript)
- README.txt

Before publishing:
1. Add your chosen song to this folder and name it music.mp3.
2. Set all Google Drive photos and the video to "Anyone with the link — Viewer".
3. Upload the folder to GitHub and deploy with Vercel.

The gallery contains all seven supplied photo links. If a thumbnail cannot load,
the card displays a fallback and a link to open the original Drive photo.
The video is embedded from the supplied Google Drive preview link.
The music player waits for a tap because mobile browsers restrict autoplay.
